# Contributing to Godot Tailscale P2P

Thank you for your interest in contributing to the Godot Tailscale P2P project! We welcome contributions from everyone. Below are the setup instructions and guidelines for developers who want to work on this project.

## Setup Instructions

### For Windows Developers
1. Ensure you have the latest version of [Godot](https://godotengine.org/download/windows).
2. Install [Visual Studio](https://visualstudio.microsoft.com/) with C++ development tools.
3. Clone the repository:
   ```bash
   git clone https://github.com/johnson270cpu/godot-tailscale-p2p.git
   cd godot-tailscale-p2p
   ```
4. Open the project in Godot and set up any required dependencies.

### For macOS Developers
1. Install [Godot](https://godotengine.org/download/mac). You can also use Homebrew:
   ```bash
   brew install --cask godot
   ```
2. Clone the repository:
   ```bash
   git clone https://github.com/johnson270cpu/godot-tailscale-p2p.git
   cd godot-tailscale-p2p
   ```
3. Open the project in Godot and set up any required dependencies.

### For Android Developers
1. Install [Android Studio](https://developer.android.com/studio).
2. Set up the Android SDK and NDK in Android Studio.
3. Clone the repository:
   ```bash
   git clone https://github.com/johnson270cpu/godot-tailscale-p2p.git
   cd godot-tailscale-p2p
   ```
4. Open the project in Godot, and configure the Android build settings.

## General Development Guidelines
- Please ensure you follow the project's coding standards and conventions.
- Make sure to thoroughly test your changes before submitting.
- Use meaningful commit messages that explain the changes made.
- Open an issue or discussion for larger changes to get feedback before implementation.

Happy coding!
