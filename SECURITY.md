# Report Security Vulnerabilities

If you discover a security vulnerability in this project, please report it as soon as possible. We take security seriously and are committed to addressing vulnerabilities promptly.

## Reporting Steps
1. **Email**: Send an email to [security@yourdomain.com](mailto:security@yourdomain.com) detailing the vulnerability and how it can be reproduced.
2. **Confidentiality**: Please include enough detail to ensure we can replicate the issue, but avoid public disclosure until the vulnerability has been addressed.
3. **Acknowledgment**: We will acknowledge receipt of your report and provide updates on the resolution timeline.

Thank you for helping us keep this project secure!
